# 공문서 모아보기 도우미

K-에듀파인 문서관리카드를 한 창에 모아보고 수정할 수 있는 윈도 프로그램입니다. 에듀파인 공식 프로그램은 아닙니다.

만든 이: **전남온라인학교 김우주** · 의견: **k203719@ai.jne.kr**

## 내려받기

**[gongmun-card-helper.exe 내려받기](https://github.com/cos2104/gongmun-card-helper-release/releases/latest/download/gongmun-card-helper.exe)** (늘 최신 판)

아무 폴더에 두고 실행합니다. 새 판이 나오면 앱 위쪽 [업데이트] 단추로 바로 바꿀 수 있습니다(서명 확인 뒤 바꿈).

필요한 것: 윈도 10·11, K-에듀파인이 깔린 PC. 있으면 더 좋은 것: 한글, MS 오피스.

### 'Windows의 PC 보호' 창이 뜨면

브라우저로 받은 파일이라 처음 한 번 뜰 수 있습니다. **추가 정보 → 실행**을 누르거나, 파일 오른쪽 단추 → 속성 → **차단 해제**를 체크합니다. 앱 안 [업데이트]로 바꿀 때는 뜨지 않습니다.

## 할 수 있는 것

1. 에듀파인에서 공문을 열면 문서관리카드와 첨부파일을 한번에 볼 수 있어요
2. 기안문을 한 화면에서 보고 수정할 수 있어요
3. 문서번호나 시행번호를 바로 복사할 수 있어요
4. 본문을 드래그해서 복사할 수 있어요

- 목록: 공문 온 날짜 · 날짜순 정렬 · 전체 체크 · 체크 닫기 / 전체 닫기
- 같은 문서가 두 번 열리면 먼저 연 카드를 닫을지 물어요
- 닫기를 눌렀을 때 시작표시줄 알림 영역으로 숨길 수 있어요

카드가 크게·가로로 보이면: 에듀파인 오른쪽 위 개인설정 → 개인문서환경 설정 → 문서관리카드 UI 유형 **보통**.

결재·발송은 하지 않습니다(보기 · 저장 · 창 정리만).

이 저장소에는 실행 파일만 올립니다.
