# 공문서 모아보기 도우미

K-에듀파인 문서관리카드를 한 창에 모아 보고, 본문·첨부를 옆 칸에서 바로 보는 윈도 프로그램입니다. 에듀파인 공식 프로그램은 아닙니다.

만든 이: **전남온라인학교 김우주** · 의견: **k203719@ai.jne.kr**

## 내려받기

[최신 판](https://github.com/cos2104/gongmun-card-helper-release/releases/latest)에서 `gongmun-card-helper.exe`를 받아 아무 폴더에 두고 실행합니다.
새 판이 나오면 앱 위쪽 [업데이트] 단추로 바로 바꿀 수 있습니다.

필요한 것: 윈도 10·11, K-에듀파인이 깔린 PC. 있으면 더 좋은 것: 한글, MS 오피스.

이 저장소에는 실행 파일만 올립니다.
